# report-card-generator

Renders one PNG report card per student from a grade summary CSV: a header
with the student's name and level change, a grid of per-subject scores, the
total, a radar chart of skill areas, and a teacher-comment box. The comment
is either typed by hand per student or produced by a small rule-based
"learner type" classifier in `learner_profile.py`. Pillow only; no other
dependencies.

The input is the summary CSV written by the companion
[desk-tools](https://github.com/hyunsoorayshin/desk-tools) grade summariser
(same columns, same `=== 주2 (N명) === Cutline: ...` section rows). The two
tools chain together but this repository does not depend on that one; a
synthetic input file is included so it runs on its own.

## Why I built it

While teaching at an English academy in Seoul I had, each term, a
spreadsheet of averaged scores and a level decision for every student, and
a stack of report cards to produce from it. I wanted a consistent, decent
looking card that could be generated for a whole class in one run, with a
radar chart so parents could see the shape of a student's strengths rather
than a wall of numbers, and a comment box I could either fill in myself or
seed with a sensible default. I built it independently, on my own time.

## What this is not

- **Not** official infrastructure of any school or academy, and **not** an
  assigned work product.
- Contains **no real student data**. `sample_data/sample_summary.csv` is
  generated by `make_sample_data.py`; every name (`학생일StudentA`, ...) and
  score is invented.
- The subject column names are **generic placeholders** (`Vocabulary Test`,
  `Reading`, `Science Presentation`, `Enrichment Test`, ...). Rename them in
  `RADAR_CATEGORIES` and `learner_profile.CLUSTERS` to match your own CSV.
- No QR code or logo is bundled. If you drop a `qr.png` next to the script
  it is pasted top-right; otherwise nothing is drawn there.

## About the "learner type" classifier (plain answer)

`learner_profile.py` assigns each student one of six labels (Star Academic,
Communicator, Creative Writer, Diligent Worker, Science-Logic Thinker,
Emerging Learner) and prints a matching paragraph and table on the card.

**It is six threshold rules, evaluated in order, on the averages of five
hand-picked groups of subject columns.** For example: "if total ≥ 80 and the
test-cluster average ≥ 85 and either the oral or the writing cluster ≥ 75,
label Star Academic". The numbers are constants the author chose. Nothing is
fitted, trained, calibrated, or validated on data. See `_classify()`.

The labels and the rubric text on the card mention Sternberg, Bloom,
Gardner, Kolb, Dweck, Vygotsky and Krashen. **Those are descriptive labels
attached to each type, not an implemented method.** The code does not
operationalise any of those theories; it compares averages to cutoffs. Treat
the auto-comment as a starting point for a teacher to edit, not as an
assessment.

## How to run

Python 3.9+ and Pillow. A font with Hangul glyphs is needed for the Korean
labels; the script looks for Apple SD Gothic Neo on macOS and Malgun Gothic
on Windows and falls back to Pillow's default font otherwise.

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

python3 make_sample_data.py                 # (re)writes sample_data/sample_summary.csv
python3 report_card.py --teacher all        # -> output/<teacher>/<class>/<name> Report Card.png
```

Without `--teacher` the script lists the teacher tags found in the class
names and asks which one to generate for. Other options: `--csv-dir` and
`--out-dir`. Cards for students whose status is `DOWN` are also listed in
`output/<teacher>/level_down_students.csv`.

### Settings

At the top of `report_card.py`:

| Setting | Meaning |
|---|---|
| `COL_CLASS`, `COL_NAME`, `COL_LEVEL`, `COL_STATUS`, `COL_TOTAL` | Header names in the CSV (`반명` = class, `원생명` = student). |
| `SCORE_START_COL` | Index of the first subject column; columns ending in `Average` are skipped. |
| `AUTO_COMMENT` | `True` uses the classifier for students without a manual comment. |
| `COMMENT_OVERRIDES` | Manual comments keyed by the name exactly as in the CSV. Always win. |
| `COMMENT_PROFILE` | Module name providing `get_comment()`; swap in your own. |
| `RADAR_CATEGORIES` | Radar axes and which columns average into each. |
| `RADAR_SCALE_BANDS` | Score-to-0..5 bands for the radar. |
| `QR_PATH` | Optional image pasted top-right when the file exists. |
| `SCALE` | Render resolution multiplier. |

### Input format

```
반명,원생명,Level,Status,주,Test Count,<subjects...>,Track A Average,Track B Average,Total Average
=== 주2 (8명) === Cutline: Lv2: 80 / Lv3: 70 / Lv4: 60,,,...
G3-21M(TeacherA) / G3-21TH(TeacherB),학생일StudentA,2,STAY,2,Track A: 7 / Track B: 8,...
```

- Section rows starting with `===` carry the cutlines used on the card.
- The class cell is `G<grade>-<level><section><day>(<teacher>)`; the tag in
  parentheses selects the teacher folder.
- `Level` is `2`, `3`, `4` or `P`; `Status` is `UP`, `STAY`, `DOWN` or `P`.
  Lower number = higher level. The card derives the final level from the two.
- Names are `<Korean><English>` with no separator (`학생일StudentA`); the card
  splits them at the first Latin letter.
